# CENIZA

Arcade para el reto [Build & Play](https://www.open2.io/build-and-pitch/play) de Open2.

Una brasa sube por la chimenea. Toca el lado libre. Si rozas el borde, se apaga.

## Cómo jugar

- Toca la mitad izquierda o la derecha, o usa A / D y las flechas.
- Espacio empuja hacia el lado que tiene más aire.
- La chimenea se estrecha y se mueve. El número es la altura.
- M apaga el sonido.

## El reto

Un solo `index.html`. Sin librerías, sin imágenes, sin audio y sin archivos de fuentes. El archivo pesa menos de 32 KB.
